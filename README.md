# dsi_ii_08_projeto-crud-gabi_01
Apresentação do projeto CRUD de cadastro de amigos – Programação Web II.

Projeto CRUD - Cadastro de Amigos

Programação Web II

Este repositório apresenta o projeto desenvolvido para a disciplina de
Programação Web II.

Sobre o projeto

O sistema tem como objetivo realizar o cadastro e gerenciamento de amigos
por meio de uma aplicação web.

## Funcionalidades

- Sistema de login
- Cadastro de amigos
- Consulta de registros
- Alteração de dados
- Exclusão de registros
- Operações CRUD
- Integração com banco de dados

## Tecnologias

- HTML
- CSS
- PHP
- MySQL
- SQL
